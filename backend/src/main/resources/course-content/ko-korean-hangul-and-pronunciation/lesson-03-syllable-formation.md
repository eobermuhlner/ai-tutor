## Grammar Focus

### Complex Syllable Block Arrangements
**Rule:** Hangul syllables can have multiple components arranged in specific patterns.

**Vertical Arrangement:** For syllables with vertical vowels
- Consonant on left, vowel on right
- Example: **가** (ㄱ + ㅏ)
- Example: **하** (ㅎ + ㅏ)
- Example: **타** (ㅌ + ㅏ)

**Horizontal Arrangement:** For syllables with horizontal vowels
- Consonant on top, vowel below
- Example: **고** (ㄱ + ㅗ)
- Example: **도** (ㄷ + ㅗ)
- Example: **하** (ㅎ + ㅗ)

**Complex Arrangement with Final Consonants:**
- For CVC (Consonant-Vowel-Consonant) structure
- Example: **간** = ㄱ (top-left) + ㅏ (bottom-right) + ㄴ (bottom) 
- Example: **한** = ㅎ (top-left) + ㅏ (bottom-right) + ㄴ (bottom)

### Multi-Syllable Word Formation
**Rule:** Korean words are composed of multiple syllable blocks arranged horizontally.

**Examples:**
- **안녕 (annyeong)** = 안 (a) + 녕 (nyeong)
- **학교 (hakgyo)** = 학 (hak) + 교 (gyo)
- **학생 (haksaeng)** = 학 (hak) + 생 (saeng)
- **한국어 (hangugeo)** = 한 (han) + 국 (guk) + 어 (eo)

### Syllable Block Construction Rules
**Rule:** Each syllable block is a complete unit that cannot be separated.

**Basic Patterns:**
1. **CV (Consonant + Vowel):** 가, 도, 수
2. **CVC (Consonant + Vowel + Consonant):** 간, 돈, 산
3. **CCV (Consonant + Consonant + Vowel):** 괜 (ggwaen), 쌍 (ssang)

**Complex Patterns:**
- The first consonant determines the arrangement (vertical vs horizontal)
- Vowel placement depends on whether it's vertical or horizontal
- Final consonant (받침) always goes at the bottom of the block

### Spacing Rules
**Rule:** Korean words are written as separate units with spaces between words, not syllables.

**Examples:**
- **안 녕 하 세 요** (incorrect spacing - spaces between syllables)
- **안녕 하세요** (correct spacing - space between words)
- **한국 사람** (correct spacing between words)
- **나는 학생이에요** (correct spacing between words)

### Pronunciation Considerations
**Key Points:**
1. Syllables are pronounced as complete units
2. The last consonant of one syllable affects the first consonant of the next
3. Some final consonants sound the same (assimilation rules)
4. Double consonants between syllables are pronounced as tense consonants

## Cultural Notes

- Korean writing system is unique in organizing characters into blocks based on syllables
- Proper spacing is crucial for readability in Korean
- Koreans appreciate when non-native speakers understand the block structure of Hangul
- Understanding syllable boundaries is important for grammar (which is based on syllable patterns)
- Korean textbooks and signs use proper spacing which helps with comprehension
- The block structure makes Korean text visually distinct from other languages
- Learning proper syllable formation helps with understanding Korean grammar later
- Korean speakers often comment positively on the neatness of properly formed Hangul blocks
- The spacing between words (not syllables) is important for meaning distinction
- Korean handwriting culture emphasizes the importance of properly formed syllable blocks
