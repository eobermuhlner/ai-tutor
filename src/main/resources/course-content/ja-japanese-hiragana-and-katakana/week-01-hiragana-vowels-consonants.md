## Grammar Focus

### Basic Hiragana Syllabary Structure

**Rule:** Hiragana consists of 46 basic characters representing syllables. Each character represents a consonant-vowel combination or a single vowel.

### Vowel Sounds (母音 - boin)
**Rule:** The five basic vowels form the foundation of all hiragana sounds.

| Hiragana | Romaji | Pronunciation |
|----------|--------|---------------|
| **あ** | a | a as in "father" (short) |
| **い** | i | i as in "machine" (short) |
| **う** | u | u as in "rule" (short) |
| **え** | e | e as in "bed" (short) |
| **お** | o | o as in "go" (short) |

### K-column (k- sounds)
**Rule:** These characters combine the consonant "k" with each vowel.

| Hiragana | Romaji | Pronunciation |
|----------|--------|---------------|
| **か** | ka | kah |
| **き** | ki | key |
| **く** | ku | koo |
| **け** | ke | keh |
| **こ** | ko | koh |

### S-column (s- sounds)
**Rule:** These characters combine the consonant "s" with each vowel. **し** is pronounced "shi", **つ** is pronounced "tsu".

| Hiragana | Romaji | Pronunciation |
|----------|--------|---------------|
| **さ** | sa | sah |
| **し** | shi | shee |
| **す** | su | soo |
| **せ** | se | seh |
| **そ** | so | soh |

### T-column (t- sounds)
**Rule:** These characters combine the consonant "t" with each vowel. **ち** is pronounced "chi", **つ** is pronounced "tsu".

| Hiragana | Romaji | Pronunciation |
|----------|--------|---------------|
| **た** | ta | tah |
| **ち** | chi | chee |
| **つ** | tsu | tsu (like "s" + "oo") |
| **て** | te | teh |
| **と** | to | toh |

### N-column (n- sounds)
**Rule:** These characters combine the consonant "n" with each vowel.

| Hiragana | Romaji | Pronunciation |
|----------|--------|---------------|
| **な** | na | nah |
| **に** | ni | nee |
| **ぬ** | nu | noo |
| **ね** | ne | neh |
| **の** | no | noh |

### Pronunciation Guide
**Key Points:**
1. Japanese vowels are pure and shorter than English vowels
2. Each syllable gets equal stress and timing
3. The consonant sound blends directly into the vowel sound
4. There are no silent letters or diphthongs like in English

## Common Mistakes to Watch

- Wrong form → Correct form (explanation)
- **し (shi)** → **si** (wrong: shi is correct, 'si' doesn't exist) ✓
- **ち (chi)** → **ti** (wrong: chi is correct, 'ti' doesn't exist) ✓
- **つ (tsu)** → **tu** (wrong: tsu is correct, 'tu' doesn't exist) ✓
- **ふ (fu)** → **hu** (wrong: fu is correct, 'hu' doesn't exist) ✓
- **し (si)** → **し (shi)** (wrong → right) ✓
- **ち (ti)** → **ち (chi)** (wrong → right) ✓
- **つ (tu)** → **つ (tsu)** (wrong → right) ✓
- **す (su)** → **し (shi)** (confusing similar-looking characters) ✓
- **と (to)** → **な (na)** (confusing characters that look similar) ✓
- **め (me)** → **る (ru)** (common confusion among beginners) ✓

## Cultural Notes

- Hiragana characters are written in cursive, flowing style
- Each character has a specific stroke order that should be followed for proper learning
- Mastering hiragana is foundational to learning Japanese - all Japanese words can be written in hiragana
- Japanese people appreciate when foreigners make effort to learn the writing systems properly
- Handwriting quality is important in Japanese culture
- Practice with proper paper that has guidelines for correct character proportions
- Learning kana first helps with pronunciation accuracy before adding kanji complexity
